# 💰 Personal Expense Tracker

A simple **frontend Personal Expense Tracker** that helps users record, manage, and track their daily expenses.

## ✨ Features

* 💵 Add income and expenses
* 📝 Add expense details
* 📊 View total income
* 💸 View total expenses
* 💰 Calculate balance
* 🗑️ Delete transactions
* 📱 Responsive design
* 🎨 Simple and clean interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure


Personal-Expense-Tracker/
│
├── index.html
├── style.css
└── script.js


## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add your income and expenses.
5. Track your total balance.

## ⚠️ Note

This is a **frontend-only project**. Data is managed on the client side and does not require a backend or database.
